# LIB_PUBLIC

The public face of the work: the page that presents the vibecoding interface (Vibecode3D, xt3d)
and the LIB_* libraries, for itch.io and anyone who finds them. The owner's direction is in
`about_LIB_PUBLIC.txt` (minimalist; "the human's spirit, the ghost in the machine").
Say xTalk / HyperCard in public text.

| File | What |
|---|---|
| `index.html` | the page |
| `screens/` | screenshots and face bitmaps the page shows |
| `about_LIB_PUBLIC.txt` | the owner's brief |
| `install/` | a simulated Steam-style install of Vibecode3D and its games on V:, and the people who escape it (`install/README.md`) |
